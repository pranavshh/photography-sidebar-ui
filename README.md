# Photography Classes Sidebar UI

A clean, responsive, and modern side navigation menu UI built with pure HTML5, CSS3, and FontAwesome icons[cite: 2, 3]. This project features a toggleable slide-out navigation panel controlled purely through CSS checkbox states, complete with social media icons and smooth layout transitions[cite: 3].

## ✨ Features

* **Pure CSS Toggle Interaction:** Uses an invisible checkbox (`#check`) and CSS sibling selectors (`~`) to control the sidebar toggle without needing any JavaScript[cite: 3].
* **Responsive Slide-in Effect:** Smooth sliding animation that brings the menu into view from the left[cite: 3].
* **Glassmorphism / Semi-transparent Styling:** Designed with dark translucent backgrounds (`rgba`) and custom box shadows[cite: 3].
* **Custom Font Integration:** Styled with Google Fonts (**Poppins**) for a clean, professional typography hierarchy[cite: 2, 3].
* **Interactive Hover States:** Includes smooth transitions, scaling effects, and shadow highlights for navigation items, close/open buttons, and social links[cite: 3].

## 🛠️ Technologies Used

* **HTML5**[cite: 2]
* **CSS3 (Flexbox & Positioning)**[cite: 3]
* **FontAwesome 6** (for UI icons)[cite: 2, 3]
* **Google Fonts (Poppins)**[cite: 2, 3]
